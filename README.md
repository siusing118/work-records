# 員工工作紀錄

獨立用嚟記員工工時同收費嘅手機版工具，無需登入、無需後端伺服器。

## 使用網址

開啟（可用電話瀏覽器，亦可「加入主畫面」）：

**https://siusing118.github.io/work-records/**

- iPhone：用 Safari 打開後，撳分享鈕 →「加入主畫面」
- Android：用 Chrome 打開後，撳選單 →「加入主畫面」／「安裝應用程式」

## 資料儲存在邊

所有員工、收費設定同工作紀錄，都只儲存在**你而家用緊嗰個瀏覽器**（localStorage）。

- 唔會上傳到 GitHub 或任何伺服器
- 換一部電話、另一個瀏覽器，或清除網站資料，就會睇唔到舊紀錄
- Safari 同 Chrome 即使喺同一部電話，資料都唔共用

## 匯出／匯入備份

頁面右上角（手機喺標題下面）有：

- **匯出備份**：下載一份 JSON 檔，建議定期存低
- **匯入備份**：用之前匯出嘅 JSON 覆蓋此瀏覽器嘅資料（匯入前會再確認）

換機或換瀏覽器時，先喺舊機匯出，再喺新機匯入。

## 計費方式

每位員工可設定四種單價。每筆記錄揀一種：

| 類型 | 計法 |
| --- | --- |
| 時薪 | 時薪 × 時數 |
| 單 job | 單價 × 件數 |
| OT | OT 時薪 × OT 時數 |
| 其他 | 固定額 +（單價 × 數量）；可只用其中一樣，或兩樣一齊加 |

新增或編輯時會將當時用嘅單價（同「其他」名稱）鎖定喺該筆記錄；之後改收費設定唔會改舊帳。新紀錄即時計入總數，亦可編輯、作廢／恢復計入，或刪除。總數頁按月份（Asia/Hong_Kong）顯示每人四種小計同全部總數。

金額以四捨五入至兩位小數計算。
